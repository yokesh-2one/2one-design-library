# DLS Feedback

Users: log feedback about the 2one DLS here. Add a new entry at the **top** of the
log using the template below (or open a GitHub issue). A 2one admin reviews these to
prioritise what to improve next.

**How to submit:** edit this file and open a pull request, or file an issue at
`github.com/yokesh-2one/2one-design-library/issues`.

## Template

```
### [YYYY-MM-DD] — <short title>
- Type: bug | request | question | praise
- Area: brand | tokens | component:<name> | template | docs | guide-app | other
- From: <name or role, optional>
- Detail: <what happened / what you need, and why>
- Status: new
```
